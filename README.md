# LSTM-Based Text Generation Using Shakespeare

## 1. Project Overview

This project implements a text generation model using Long Short-Term Memory (LSTM), a type of recurrent neural network. The model learns patterns from Shakespeare's works and generates new text based on a given seed phrase.

The project uses Python and TensorFlow/Keras to preprocess text, train the LSTM model, and generate new word sequences.

## 2. Objectives

- Load and preprocess a text dataset.
- Convert words into numerical representations.
- Prepare input-output sequences for next-word prediction.
- Build and train an LSTM-based neural network.
- Generate text from different seed phrases.
- Evaluate the model using training and validation metrics.

## 3. Technologies Used

- Python
- TensorFlow and Keras
- NumPy
- Scikit-learn
- Regular Expressions
- Google Colab

## 4. Dataset

The dataset is Shakespeare's Complete Works from Project Gutenberg.

Dataset link: https://www.gutenberg.org/ebooks/100

The text is converted to lowercase, punctuation and digits are removed, and whitespace is normalized. The cleaned text is then tokenized into individual words.

## 5. Project Workflow

1. Download the Shakespeare text dataset.
2. Clean and preprocess the text.
3. Tokenize words and convert them into numerical IDs.
4. Create sequences containing five input words and one target word.
5. Split the sequences into training and validation sets.
6. Build an LSTM-based text generation model.
7. Train the model using Adam optimization and sparse categorical cross-entropy loss.
8. Use early stopping and model checkpointing during training.
9. Generate text using different seed phrases.

## 6. Model Architecture

The model consists of the following layers:

- **Embedding Layer:** Converts word IDs into dense numerical vectors.
- **LSTM Layer:** Learns sequential patterns from the input words.
- **Dropout Layer:** Helps reduce overfitting during training.
- **Dense Layer:** Predicts probabilities for the next word using softmax activation.

The model uses the Adam optimizer and sparse categorical cross-entropy as its loss function.

## 7. Training Configuration

- Sequence length: 5 words
- Embedding dimension: 64
- LSTM units: 128
- Dropout rate: 0.2
- Batch size: 256
- Maximum epochs: 5
- Training subset: 150,000 sequences
- Validation subset: 20,000 sequences
- Early stopping and model checkpointing: Enabled

These examples demonstrate that the model learns some vocabulary and local patterns from Shakespeare's works. However, the generated text is not consistently grammatical or coherent.

## 9. Results and Observations

During training, the model's training and validation accuracy improved, while validation loss decreased. This indicates that the model learned some patterns from the training data.

The initial model has limited text coherence. Further experimentation with sequence length, vocabulary size, training duration, and model architecture could improve generation quality.
